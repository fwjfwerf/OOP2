# Таймер і секундомір

Навчальний C++17-проєкт для демонстрації бібліотеки класів предметної області «Таймер».

- `TimeCounter` — базовий клас із методами запуску, зупинки та скидання. Для вимірювання часу він використовує `std::chrono::steady_clock`.
- `Timer` — похідний клас, який показує час до завершення зворотного відліку. Скидання повертає початкову тривалість.
- `Stopwatch` — похідний клас, який показує накопичений час. Після зупинки відлік можна продовжити.

Метод `getTime()` повертає час у мілісекундах. У `main.cpp` функція `printTime()` приймає посилання на базовий клас і викликає реалізацію методу відповідного об’єкта.

Заголовкові файли розміщені в `lib/include`, реалізації — у `lib/src`. У `lib/CMakeLists.txt` створюється статична бібліотека `time_counters`. Головний `CMakeLists.txt` підключає її до програми `timer_demo` з файлу `src/main.cpp`.

## Збірка та запуск

У PowerShell з кореня проєкту:

```powershell
cmake -S . -B build
cmake --build build --config Debug
```

Запуск з Visual Studio (MSVC):

```powershell
.\build\Debug\timer_demo.exe
```

Запуск з одноконфігураційним генератором, наприклад Ninja:

```powershell
.\build\timer_demo.exe
```

На Linux і macOS після збірки одноконфігураційним генератором виконай `./build/timer_demo`.
